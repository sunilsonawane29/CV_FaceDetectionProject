# Computer Vision Project

## Project Overview
This project demonstrates image processing, feature extraction, object detection, and motion detection using Python and OpenCV.

## Technologies Used
- Python 3.12
- OpenCV
- NumPy
- Matplotlib
- scikit-image
- Ultralytics YOLO
